# TabsPanel 标签页面板重新设计

日期：2026-08-11
状态：已确认

## 需求背景

现有 `TabsPanel`（标签页面板）按窗口分组展示所有标签页。本次重新设计为**按域名分类**，并新增**全部关闭**、**按域名关闭**能力，提升批量管理标签页的效率。

## 交互规格

### 面板结构（顶部工具条 + 域名卡片列表）

```
┌────────────────────────────────────────┐
│  🌐 标签页面板          总 12 [全部关闭]  │ ← 顶部工具条
├────────────────────────────────────────┤
│ ┌─ github.com ──────────────── [关闭] ─┐ │
│ │  ● tab1 标题             github.com  │ │  ← 域名卡片（纵向堆叠）
│ │  ● tab2 标题             github.com  │ │     一个域名一张卡片
│ └──────────────────────────────────────┘ │
│ ┌─ google.com ────────────── [关闭] ───┐ │
│ │  ● tab3 标题             google.com  │ │
│ └──────────────────────────────────────┘ │
└────────────────────────────────────────┘
```

1. **分组方式**：纯按域名分组（`safeHost` 提取 hostname），同域名跨窗口的 tab 归入同一组；域名组按字母升序排列；无 URL / 解析失败的 tab 归入「其他」组（排在最后）
2. **卡片形式**：一个域名组一张卡片，卡片纵向堆叠（一列到底），面板整体滚动；卡片内是该域名的 tab 列表；单 tab 域名也显示成卡片（样式统一）
3. **卡片标题**：域名 + tab 数量 + 「关闭」按钮（关闭该域名下所有 tab）
4. **tab 行**：favicon + 标题 + 域名，点击激活该标签页并聚焦窗口（保留现有行为）；当前活动标签高亮（`lastFocusedWindow` 判定）
5. **域名关闭**：点击卡片「关闭」→ 关闭该域名下所有 tab，无需二次确认；pinned 标签先取消固定再关闭
6. **全部关闭**：点击顶部工具条「全部关闭」→ 关闭所有标签页；关闭后各窗口保留一个空白新标签页（Chrome 不允许窗口无标签，会自动新建 `chrome://newtab`），面板随之显示「暂无标签页」
7. **空组消失**：域名组内 tab 被关闭后整卡片从列表消失

## 实现方案

### `src/newTab/components/TabsPanel.tsx`

- 导出纯函数 `groupTabsByHost(tabs: Browser.tabs.Tab[]): { host: string; tabs: Browser.tabs.Tab[] }[]`：
  - 按 `safeHost(tab.url)` 分组（空 host 归入 `'其他'`）
  - 组按域名（或「其他」）字母升序排序
  - 组内保持原顺序
- 替换现有 `groupTabsByWindow`（窗口分组不再使用，删除该函数）
- 顶部工具条：左侧「标签页面板」标题 + 总标签数，右侧「全部关闭」按钮
- 域名卡片：`rounded-lg border border-border bg-background/60`（参考 `PinnedBookmarks` 卡片样式），标题行含域名 + 数量 + 关闭按钮，内部 tab 列表沿用现有 `TabItem` 行
- 关闭逻辑：
  - 域名关闭：组内 pinned tab 先 `browser.tabs.update(id, { pinned: false })`，再 `browser.tabs.remove(ids)`
  - 全部关闭：对所有窗口内 tab 执行同样逻辑（去 pinned → remove）
- `useTabs({})` 保持现有用法，数据驱动不变

### `src/newTab/components/TabsPanel.test.tsx`

- 同步更新测试：`groupTabsByHost` 替换 `groupTabsByWindow` 用例
  - 同域名跨窗口合并
  - 域名字母升序
  - 无 URL 归入「其他」且排最后
  - 空数组返回空

## 不改动

- `useTabs` hook（已支持 `query({})` 查询全部窗口）
- Header 左侧按钮、`PinnedBookmarks`、两个弹窗
- 不引入新 UI 组件库

## 验收标准

1. 面板按域名分组展示，同域名跨窗口 tab 合并，域名组字母升序
2. 每个域名一张卡片（单 tab 域名也成卡片），卡片纵向堆叠
3. 卡片标题显示域名 + tab 数量 + 关闭按钮
4. 点击卡片关闭按钮 → 该域名所有 tab 关闭（含 pinned 先取消固定），空组卡片消失
5. 顶部工具条显示总标签数 + 「全部关闭」按钮；点击后所有窗口保留一个空白新标签页，面板显示「暂无标签页」
6. 点击 tab 行激活对应标签页并聚焦窗口；当前活动标签高亮
7. 无 URL tab 归入「其他」组
8. `pnpm compile` 与 `pnpm test` 通过
