# Edge 加载项商店上架文案

提交地址：[Microsoft Partner Center](https://partner.microsoft.com/dashboard/microsoftedge/overview)，本文档字段可直接粘贴到扩展提交表单（中文）。

> 单一用途定位：**新标签页效率工具** —— 搜索、书签、标签页管理均为该用途下的子功能，与 `wxt.config.ts` 中 manifest 描述保持一致。

## 名称（显示名，≤45 字符）

```
xtTab - 新标签页效率工具
```

> 说明：商店显示名默认取自 manifest 的 `name` 字段（当前为 `xtTab`）。Edge 政策要求名称体现用途，建议在提交表单中填写上述名称；若需让商店与扩展名完全一致，需修改 `wxt.config.ts` 中 `name` 字段后重新打包。

## 简短描述

```
极简美观的新标签页效率工具：多引擎搜索与联想、书签管理置顶、标签页分组管理，一站式提升浏览效率
```

> 说明：Edge 一览页默认取 manifest `description` 字段内容，已同步更新至 `wxt.config.ts`，与上述文案一致。

## 详细描述（中文，250–5000 字符）

```
xtTab 是一款极简美观的新标签页效率工具，替换浏览器默认的新标签页，将搜索、书签与标签页管理整合到一个高效、美观的页面中，一站式提升日常浏览效率。

【聚合搜索】
- 内置百度、GitHub、淘宝、京东、小红书、掘金等多个搜索引擎，下拉一键切换
- 输入时实时联想推荐，支持方向键选择、回车直接搜索
- 自动记录搜索历史，可在设置中一键关闭

【书签管理】
- 以文件夹形式浏览全部书签，支持书签搜索
- 常用书签置顶到主页卡片区，一键直达
- 自动展示网站真实图标，更易辨认
- 书签打开方式（新标签页/当前页）可配置

【标签页管理】
- 按域名分组展示所有窗口的标签页，一目了然
- 支持按域名关闭、全部关闭（自动保留当前活动标签页），操作高效安全

【个性化设置】
- 内置精美背景图，新标签页赏心悦目
- 支持自定义搜索引擎（添加/删除）
- 键盘快捷键：快速打开书签与设置弹窗

【使用方法】
安装后直接打开新标签页，即可使用全部功能。

【权限说明】
- tabs / bookmarks：用于新标签页内的标签页分组管理、关闭操作与书签展示
- storage：本地保存您的设置与搜索历史

【隐私说明】
所有设置、搜索历史与书签置顶数据均仅保存在您本地的浏览器存储中，不会上传至任何服务器；搜索联想由所选搜索引擎的联想接口提供。
```

## 提交表单其他项建议

| 项目 | 建议 |
|---|---|
| 分类 | 生产效率（Productivity）或 搜索工具（Search Tools） |
| 图标 | 使用 `public/icon/` 下现成图标（Edge 要求 ≥128×128，已具备 128） |
| 截图 | 1–6 张，建议 1280×800 或 640×400：新标签页主页、搜索联想、书签弹窗、标签页管理面板 |
| 隐私政策 | 若提交时询问隐私政策 URL：本扩展数据均本地存储，可据实说明"不收集任何个人数据"；联想请求仅发往用户所选搜索引擎 |

## ⚠️ 上架前待处理事项

1. **`<all_urls>` 主机权限**：`host_permissions: <all_urls>` 权限范围较大，Edge 审核可能要求说明用途（当前联想代理、content 注入需要）；如确认 content 注入暂无实际功能，建议收紧权限后再提交。
